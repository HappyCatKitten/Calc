# Calc 1.1.0

The app is now named **Calc**, with updated launchers, packages and repository links. The Brainfuck numeric engine is unchanged.

- Optional Catacalc mode with circular buttons, the approved caterpillar artwork and an illustrated history panel.
- Both standard and scientific layouts, optional history and persistent theme preferences.
- Existing Brainfuck Calculator and Obsidian Calculator history and preferences are imported automatically.
- Native UI checks cover mouse input, expression editing, filtered history recall, scientific/compact layouts, restart persistence and theme switching.

## Downloads

- `calc_1.1.0_amd64.deb`: Debian/Ubuntu/Pop!_OS installer.
- `calc-1.1.0-linux-x86_64.tar.gz`: standalone app with bundled Qt; extract and run `./AppRun`, or run `./install.sh` for a per-user installation.
- `SHA256SUMS`: checksums for the downloads.

Built for Linux x86_64, glibc 2.35 or newer. Tested on Pop!_OS 22.04/X11. Wayland plugins are bundled but not validated.
